Use optional stable series ID and positive part number; published locale-local previous/next links at both ends. Existing standalone posts unchanged. Never edit ignored personal content; document the authoring contract and test synthetic entries.

Generate localized route-specific 1200x630 PNGs at build from actual public HTML using installed rendering tools/local fonts; preserve explicit images and default fallback. No SSR migration, dependencies or remote services. Test emitted image references and exclusions.

No merge authorization is implied.

- S7: "Veo que localmente las imagenes og de las paginas apuntan a arturonavax.dev y asi no puedo hacer la prueba local si no esta desplegado este cambio, mejoralo para aumentar la versatilidad de prueba sin afectar en nada al rendimiento ni al SEO." Add an explicit loopback-only local build/preview with local social-image origin and separate ignored output; default production generation/metadata remains unchanged, with no added production JS or requests.
- S8: "Y haz que cuando se cambie de idioma o tema no debe subir todo el scroll, debe mantenerse donde esta." Preference changes preserve the current scroll position; ordinary page navigation retains its intentional reset. Verify with actual visible-control clicks, not automation scroll-into-view artifacts.
